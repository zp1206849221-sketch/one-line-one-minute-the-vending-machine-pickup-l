# One Line, One Minute: The Vending Machine Pickup Line

A one-line entry for the make.fun vending machine pickup line contest. A lovesick vending machine works its whole world into a single breath — exact change, humming coils, the coin slot, a coin dropping in — and saves its best invitation for last: press my buttons.

The line (149 characters):

> Are you exact change? My coils have been humming all day for someone who fits my slot perfectly — you just dropped in, so go ahead, press my buttons.

## Run

```sh
python3 main.py
```

This writes the pickup line to `/output/entry.txt` (creating the directory if needed).
